# 试卷打印

点击试卷工具栏的打印按钮，或按 `Ctrl/Cmd + P` 打开打印选项。

- 默认打印答案，并将答案汇总到文末的新一页；也可选择在原题位置显示答案。
- 取消「打印答案」可生成无答案试卷，填空保留书写空间。
- 「打印试题概要信息」默认关闭，可按需开启。
- 选项在当前页面内保留。浏览器菜单直接打印使用最近确认的选项；尚未确认时使用默认值。
- 打印稿使用 A4 布局，去掉导航、目录、工具按钮和相关试卷，保留来源链接与授权说明。最终纸张、缩放及浏览器页眉页脚由系统打印窗口控制。

## 实现与来源

参考同源项目 `byrdocs-wiki-print` v0.1.3（提交 `277e656`）的打印选项和答案附页组织方式，将适合站点的功能集成到原生打印入口。

- `src/components/ExamPrintDialog.astro`：选项界面。
- `src/scripts/examPrint.ts`：打印生命周期。创建独立 DOM 副本，在副本上展开答案、清除选择结果和移除界面元素；打印完成、取消预览或调用失败后清理副本。不会切换原页面答案，也不会写入答题记录。复制的单选输入移除 `name`，避免加入原页面选项组。
- `src/scripts/printAppendix.ts`：提取填空、选择题和解答，保留显式题号、列表起始编号及小标题。无答案项和空章节跳过，解答内部的标题和嵌套答案不参与题目分组。同一题多个答案按原顺序保留。
- `src/styles/print.css`：仅在打印媒体中显示副本，使用浅色排版，题图取消浮动并限制尺寸，答案附页另起一页。

站点无需扩展的打印接管、悬浮按钮和更新提醒，因此未移植这些功能。参考项目不作修改。

## 回归验证

先运行开发服务器（附页边界测试通过 Vite 导入源模块）：

```sh
pnpm dev --host 127.0.0.1 --port 4331
```

另一个终端运行：

```sh
pnpm check:print
# 也可指定开发服务器地址：
pnpm check:print http://127.0.0.1:4321
WIKI_SITE_URL=https://wiki.byrdocs.org pnpm validate
```

浏览器脚本使用 `npx @playwright/cli`，需可用的 Node/npm、Chrome，以及首次获取 CLI 所需的网络。使用专用 `neowiki-print` 会话；会话由脚本创建并关闭。日志与四份 PDF 保存在已忽略的 `output/playwright/`，不要提交生成文件。

2026-10-03 验证记录：

- Chromium 154：58 项断言通过。覆盖三种答案模式、默认选项、概要信息、深色主题、快捷键、取消选项、浏览器菜单打印、重复生命周期、打印异常清理。
- 在部分填空已展开、解答已打开、选择题已提交的状态下，打印期间和结束后原页面 DOM、选中项与 `exam-state:` 存储保持一致。
- 附页覆盖跳号、残缺答案、显式题号、多选、解答内部标题、空答案及仅 SVG 的答案。
- 真实无答案试卷：40 道选择题保留，未生成空答案附页。
- 数据结构三种模式及高数试卷均导出 PDF；检查题图、公式、填空线、答案标记和附页分页。
- `pnpm validate` 通过：ESLint、Astro 检查（0 错误、0 警告）、228 页生产构建。

验证范围为 Chromium 的浏览器打印生命周期和 PDF 输出，未测试实体打印机及 Safari/Firefox 的系统打印窗口。
