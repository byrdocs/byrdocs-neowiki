### 8-4 算法设计题（50 分）

**奇怪的习俗**

某个古老而神秘的部落深信闰年寓意着吉祥，因此，他们认为如果一对男女均出生于闰年，他们的联姻将格外吉祥。更进一步，这对男女出生年份的最大公约数若越大，他们在婚后享有的幸福便越深厚。

现请你写一段程序，来看一下某对男女的年龄是否符合这种习俗。

**输入格式：**

第一行，为一个整数 $n$（$0 < n < 10$），代表共有 $n$ 对年龄；后边有 $n$ 行，每行均为用空格分隔的两个整数（所有整数均大于 0 且小于等于 2500），代表一对男女的出生年份。测试用例保证合法。

**输出格式：**

共 $n$ 行，每行依次与输入的 $n$ 对年龄对应，如果输入的两个年份都是闰年（一个年份是否是闰年按现行历法判断），则输出这两个年份的最大公约数，否则输出 `no`。

**输入样例：**

```text
2
2000 1996
1997 2000
```

**输出样例：**

```text
4
no
```

**问题：**

1. 设计函数 `isLeapYear`，功能为判断一个年份是否是闰年，请给出函数原型，并解释参数及返回值的含义。
2. 设计函数 `gcd`，功能为求两个正整数的最大公约数，请给出函数原型，并解释参数及返回值的含义。
3. 请用伪代码或 C 语言代码描述函数 `isLeapYear` 的算法实现。
4. 请用伪代码或 C 语言代码描述函数 `gcd` 的算法实现（请用辗转相除法，且不允许使用递归）。
5. 请用伪代码或 C 语言代码描述 `main` 函数的算法实现，`main` 函数需要调用上述所设计的子函数。
