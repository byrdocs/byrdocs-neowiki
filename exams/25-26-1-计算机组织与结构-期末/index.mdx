一个超标量处理器的结构如图，如果不存在资源冲突和数据依赖问题，该处理器每个时钟周期可以发射两条指令。该处理器包含两条流水线，每条有四个处理阶段：取指、译码、执行和存储。每条流水线都有各自的取指单元、译码单元和存储单元。执行阶段有四个功能单元（乘法器、加法器、逻辑单元和加载单元）和两个存储单元，由两条流水线动态共享。此外，处理器还设有一个具有独立取指和译码逻辑的前瞻窗口，用于提前查看后续指令，以支持乱序发射。考虑在该处理器上执行以下程序：

```text
I1: Load R1, A     / R1 ← Memory(A) /
I2: Add  R2, R1    / R2 ← R2 + R1 /
I3: Add  R3, R4    / R3 ← R3 + R4 /
I4: Mul  R4, R5    / R4 ← R4 * R5 /
I5: Comp R6        / R6 ← (R6) /
I6: Mul  R6, R7    / R6 ← R6 * R7 /
```

1. 该程序中存在哪些依赖关系？
2. 对该处理器，采用顺序发射、顺序完成策略，写出该程序的时序图。
3. 采用顺序发射、乱序完成策略，重复上述分析。
4. 采用乱序发射、乱序完成策略，重复上述分析。
